Supporting Communities in Denmark

A modern, multilingual NGO website helping children, people with disabilities, and people experiencing poverty. Built with Next.js for English, Danish, and Persian speakers.

Next.js 14 TypeScript Multilingual Prisma Open Source
View on GitHub

Features

  • Multilingual: Full support for English, Danish, and Persian (RTL)
  • Admin Panel: Simple CMS for managing posts and announcements
  • MobilePay Integration: Donation banner with monthly box numbers
  • Cloudinary: Image hosting and optimization
  • Secure Auth: NextAuth with role-based access
  • Accessible: WCAG 2.1 AA compliant, fully responsive

Tech Stack

  • Framework: Next.js 14 (App Router)
  • Language: TypeScript
  • Database: PostgreSQL + Prisma ORM
  • Auth: NextAuth.js
  • Styling: Tailwind CSS
  • i18n: next-intl
